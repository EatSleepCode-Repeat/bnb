# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | :white_check_mark: |
| < 0.5.0 | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities via public GitHub issues.

Instead, please report security issues through **GitHub Private Vulnerability Reporting** on this repository, or email the maintainer directly.

All reports will be acknowledged within 48 hours, and patches will be released promptly.
